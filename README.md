## 재생기 키

| 키 | 동작 |
| --- | --- |
| → · Space | 다음 장 |
| ← | 이전 장 |
| 숫자 + Enter | 그 장으로 이동 |
| M | 소리 끄기·켜기 |
| B | 화면 가리기 |
| P | 발표자 화면 |
| H | 도움말 |
